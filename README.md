# Интернет-магазин брендов одежды

Проект по дисциплине «Программная инженерия».
Кадин Роман Александрович.

Веб-система предназначена для продажи одежды разных брендов через единый каталог. Покупатель выбирает размер и цвет, оформляет заказ и следит за его состоянием. Сотрудники магазина ведут карточки товаров, остатки и заказы.

Тема: «Разработка информационной веб-системы универсального интернет-магазина брендов одежды».

Проектные документы размещаются в папке `docs`.
