# Интернет-магазин брендов одежды

Веб-система объединяет товары разных брендов в одном каталоге. Покупатель выбирает размер и цвет, оформляет и оплачивает заказ, затем следит за его состоянием. Сотрудники магазина ведут товары, остатки и отправку.

Тема: «Разработка информационной веб-системы универсального интернет-магазина брендов одежды».

## Пользователи

Гость, покупатель, контент-менеджер, сотрудник склада и администратор. Администратор управляет учётными записями; эта роль сама по себе не даёт доступ к заказам.

## Основные возможности

- Просмотр каталога и фильтры по бренду, категории, размеру, цвету и цене.
- Выбор варианта товара и работа с корзиной.
- Оформление заказа с проверкой и резервированием остатков.
- Оплата через внешний сервис и просмотр своих заказов.
- Отмена нового заказа без ожидающей или успешной оплаты.
- Ведение карточек, остатков, сборки и отправки сотрудниками.
- Уведомления об оплате и отправке заказа.
