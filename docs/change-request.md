# Запрос на изменение CR-01

Статус: предложен, ожидает согласования. Текущая версия документации — 1.1.0.

| Поле | Содержание |
| --- | --- |
| Название | Список избранных товаров покупателя |
| Причина | Покупатель хочет сохранить понравившиеся вещи и вернуться к ним без повторного поиска. |
| Новое требование | ФТ-15, проект: после входа покупатель добавляет товар в своё избранное и удаляет его. Один товар хранится в списке один раз. Чужой список недоступен. |
| Модули | М1 проверяет владельца; М2 хранит и показывает избранные товары. |
| Модель данных | Добавить FavoriteItem с userId и productId; уникальность пары userId и productId. Сохраняется товар, а не выбранный размер; избранное не резервирует остаток. |
| Сценарий | В карточке нажать «В избранное», открыть список, выбрать товар и доступный вариант для корзины. Снятый с продажи товар помечается как недоступный. |
| Тесты | ТК-24, проект: добавить, повторить добавление и удалить товар. ТК-25, проект: запрет доступа к чужому списку и отображение снятого с продажи товара. |
| Документы | 2-requirements.md, 3-scenarios.md, 4-architecture.md, диаграмма классов и 5-uml-and-tests.md; затем user-guide.md и CHANGELOG.md. |
| Оценка | 3 рабочих дня: требование и сценарий — 1, модель и архитектура — 1, тесты и инструкция — 1. |
| Новая версия | 1.2.0: добавляется новая возможность, существующие сценарии сохраняются. |

Запрос рассматривается после текущего спринта. Пока он не согласован, ФТ-15 и ТК-24–25 существуют только в этом запросе и не входят в базовую версию.
